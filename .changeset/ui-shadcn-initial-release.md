New package: `@ranjeetk25/schema-grid-ui-shadcn`, a second UI kit built on shadcn/ui (Radix primitives), Tailwind CSS v4 and lucide-react that fulfils the same contracts as `@ranjeetk25/schema-grid-ui-mantine` — editors for all 16 field types, Radix column filters, the filter builder with live/explicit apply, the Airtable-style column panel, header menu, views, grouping, conflict prompt, import wizard and export dialog. Ships a prebuilt `styles.css` (every utility prefixed `sg:`, no Preflight) plus a Tailwind v4 source entry (`tailwind.css`).
